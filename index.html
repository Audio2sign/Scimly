Scoring Settings

How risk is scored
Role base — Admin 20 · Editor 8 · Viewer 4
+ Staleness — up to 30 pts, scaled from days since last login
+ Admin without MFA — +25
+ Stale admin / stale user flag — +15 / +10
+ Missing SCIM external ID — +10
+ Missing department or manager — +8 each
+ Paid inactive seat — +15, waste = monthly license cost
Risk is capped at 100. Readiness = 100 − average risk across all rows.
